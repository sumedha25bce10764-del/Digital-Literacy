# Digital-Literacy Portfolio
This repository contains my Digital Literacy Portfolio Project, created as part of the CSE0001 – Digital Literacy course at VIT Bhopal University.
As a Student Digital Ambassador, this project aims to help students:
Understand digital literacy
Build a professional online presence
Use digital tools effectively
Communicate professionally
Stay safe from cyber threats
The project is divided into 5 tasks, each focusing on a key aspect of digital literacy.
